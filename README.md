## Краткий паспорт проекта
- **Название:** МОСТ GovTech: Инфраструктурный мониторинг и диспетчеризация
- **Сфера:** Умный город (Smart City / GovTech)
- **Технологическая готовность:** TRL 7–8 (действующее ПО, микросервисы компьютерного зрения)
- **Основатель:** Виталий Демидов (Arizona State University Edson E+I certified)

## Архитектура решения: Триединый контур
1. **PipeVision (AI Road Vision):** Компьютерное зрение (OpenCV 5, RT-DETR v2) на бортовых регистраторах автобусов для предиктивного выявления ям и дефектов дорог на скорости до 45 FPS с субметровым GPS.
2. **CityBalance (ЖКХ и теплосети):** Балансировщик сетей на TimescaleDB. За 8.5 секунд рассчитывает схему задвижек при порыве теплосети (КТЭК) и сопоставляет ОПУ vs ИПУ.
3. **Review Shield (Super-App):** Независимый PWA веб-апп (Next.js 16 + Payload CMS 3.9) со входом по QR-кодам без скачивания и авто-оповещением в WhatsApp для ЕКЦ 109.
